# 🍕 Pizza Sales Analysis — Power BI Dashboard

An interactive Power BI dashboard built to analyze pizza sales performance, customer ordering patterns, product performance, and revenue trends.

## 📊 Project Overview

This project transforms raw pizza sales data into an interactive business intelligence dashboard using **Microsoft Power BI**.

The dashboard helps understand:

* Overall sales and revenue performance
* Best and worst performing pizza products
* Sales by pizza category and size
* Daily and monthly sales trends
* Customer ordering patterns
* Product quantity and revenue contribution

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query** — Data cleaning and transformation
* **DAX** — Measures and calculations
* **Data Visualization**
* **CSV Dataset**

## 📈 Dashboard Highlights

### Key Performance Indicators

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas per Order

### Business Analysis

* Daily and monthly revenue trends
* Sales by pizza category
* Sales by pizza size
* Top-selling pizzas

* Revenue and quantity analysis
